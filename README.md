## 📌 Featured Engineering Projects

### 1. Microstrip Rat-Race Hybrid Coupler at 3 GHz
* **Domain:** RF & Microwave Engineering / B.Sc. Capstone Thesis
* **Tools:** Keysight ADS, Ansoft Designer, Vector Network Analyzer (VNA), PCB Gerber
* **Overview:** Complete design, simulation, and laboratory validation of a 180° planar Rat-Race hybrid coupler. Evaluated matching across FR-4 and Rogers RT5880 substrates. Validated physical hardware via VNA bench testing achieving S11 = -36.5 dB, 18.42 dB isolation, and 174.4° phase balance.

### 2. [4G LTE vs. 5G NR IoT Testbed Simulation](https://github.com/roxana-mparaschiv/ns3-lte-5g-iot-testbed)
* **Domain:** Cellular Communications & Network Modeling
* **Tools:** NS-3, C++, Linux (Ubuntu), LENA, ns-3-nr, FlowMonitor
* **Overview:** Discrete-event comparative testbed benchmarking LTE against 5G New Radio under heterogeneous IoT traffic (downlink sensor telemetry & uplink bursty video). Demonstrated ~55% latency reduction and zero video packet loss under high channel load using 5G NR beamforming.

### 3. [3-Element Linear Antenna Array Simulation](https://github.com/roxana-mparaschiv/antenna-array-simulation)
* **Domain:** Electromagnetics & Wave Propagation
* **Tools:** MATLAB, Analytical Formulations
* **Overview:** Numerical modeling of a 3-element half-wavelength linear dipole array at 140 MHz. Implemented phased beam steering, HPBW narrowing from 78.0° to 26.3°, directivity calculation via 3D spherical integration (6.08 dBi), and PEC ground plane modeling via Image Theory.

### 4. Computer Vision Panorama Stitching Pipeline
* **Domain:** Computer Vision & Image Processing
* **Tools:** Python, OpenCV, NumPy, ORB, RANSAC
* **Overview:** Multi-image stitching pipeline utilizing ORB keypoint detection, Brute-Force Hamming matching, and RANSAC-driven homography estimation with seam blending and morphological black border removal.
